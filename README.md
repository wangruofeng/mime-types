# MIME 类型速查工具

一个纯前端的单文件 MIME 类型速查表，双击 `index.html` 即可使用，无需安装、无需后端、无任何外部依赖。

## 功能特性

- 🔍 **双向查询**：输入扩展名（如 `json`）、MIME 类型（如 `application/json`）或中文说明（如 `图片`）即时过滤。
- 📁 **文件名识别**：粘贴文件名（如 `archive.tar.gz`）自动提取扩展名，优先识别 `.tar.gz` 等多段后缀。
- 🏷️ **八大中文分类**：文档 / 图片 / 音频 / 视频 / 字体 / 压缩 / 代码 / 数据，支持分类分段筛选。
- 📋 **一键复制**：点击表格行复制 MIME 类型，点击行尾按钮复制扩展名。
- 📊 **实时统计**：共 N 条 · 匹配 M 条，无匹配时提示“未收录，可能为自定义格式”。
- 🎨 **深浅色主题**：跟随系统或手动切换，自动记忆到 `localStorage`。
- 📱 **自适应移动端**：小屏幕自动隐藏说明列，优化触控体验。

## 使用方式

直接用浏览器打开 `index.html` 即可：

```bash
open index.html        # macOS
# 或拖入浏览器
```

在顶部搜索框输入关键词，或选择分类即可查看结果。

## 数据覆盖

内置 592 条常见扩展名 ↔ MIME 类型映射，涵盖：

- 文档（Office、PDF、Markdown、电子书、字幕等）
- 图片（常见位图、RAW、矢量、3D 模型贴图等）
- 音频（常见有损/无损、模块音乐、游戏芯片音乐等）
- 视频（常见封装、编码码流等）
- 字体（网页字体、系统字体等）
- 压缩（压缩包、光盘映像、安装包等）
- 代码（主流编程语言、配置文件、模板等）
- 数据（JSON/XML/数据库/地理数据/API 规范等）

## 技术说明

- 单一 HTML 文件，原生 HTML / CSS / JavaScript，零依赖、零构建步骤。
- 所有数据以内嵌 JS 常量形式存在，无需网络请求。
- 所有查询与复制操作均在浏览器本地完成，不上传任何数据。
